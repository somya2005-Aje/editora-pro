Layers

No mask on the selected layer.

Brush

Paints on the active layer. Eraser uses the same size. Spacing = distance between dabs as % of brush size (25% = smooth stroke). Flow = airbrush spray amount; Strength = blur/sharpen/smudge/dodge/burn/sponge power.

Crop & Resize

Drag on the canvas to draw the crop box — drag its corner/edge handles to resize it — then:

Straighten previews live; Apply bakes it into every layer.

Selection

Delete clears to transparency on the active layer. Fill uses the brush color. Tolerance is used by Quick Selection, Wand and Color Range. Polygon lasso: tap to place points, double-tap (or Enter) to close.

Refine edges

Background

Select the subject first (any selection tool), then Delete background removes everything OUTSIDE the selection to transparency, or fills it with a color / an image.

Retouch

Skin tone (uses current selection)

Selective color

#ff3366

Skin tone and selective color work inside the current selection (or the whole layer if there is no selection). Red-eye: tap the red eye. Spot heal: tap the blemish once.

Transform

Drag the corner handles to scale (Perspective: drag corners to skew). Drag edge handles to shear. Drag the top circle to rotate. Then:

Applies to the active layer. Text/shape layers are rasterized first.

Clone / Healing

No source set. Alt-click (or long-press on touch) on the canvas to sample a source point, then paint.

Healing paints the sampled pixels with a soft feathered edge, so blemishes blend away. This is a feathered clone, not content-aware fill.

Text

Click the canvas to place the text. Click an existing text layer to select it, then edit here — changes apply live. Double-click a text layer on the canvas to edit its wording.

Shapes

Drag on the canvas to draw the shape. Each shape is its own layer — move or restyle it later.

Paint bucket

Click the canvas to flood-fill a similar-color area with the brush color. Tolerance 0 = exact color only.

Gradient

Drag on the canvas: the drag direction sets the gradient direction (linear) or its radius (radial). Colors are the foreground → background colors in the left panel. Creates a real gradient layer (or fills the selection).

Layer mask — painting

You are painting on the layer mask, not the image. Black hides pixels, white reveals them. Switch back with “Done editing mask”.

More tools

Picker, Bucket, Transform and Perspective also have keyboard shortcuts (I, G) or live in the Select / Image menus.

Design studio — new canvas

Frames

Gradient / pattern fill

Presets really create a new document at those exact dimensions. Frames add a border layer on top. Gradient/pattern fill creates a new layer (or fills the selection).

Adjustments

Adjustments are live and non-destructive — they are stored per layer and baked only on export. With a selection active and “selection only” checked, they affect just the selected area. Tint: + = magenta, − = green.

Curves, Levels, HSL and Color Balance are live and non-destructive, like the sliders above.

Filters

Filters are real pixel presets — they set the adjustment values above (plus sepia / duotone pixel math). Pick one, then fine-tune with the sliders.
