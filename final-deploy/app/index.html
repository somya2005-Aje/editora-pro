Pro Tools

Split screen, chroma key, masks, proxy preview, audio ducking and frame export. Everything here is real in the preview and in at least one export path — anything an export path cannot do is listed in the export result, never faked.

Split screen

Shows 2, 3 or 4 videos at once. Cell 1 is the V1 clip under the playhead; the other cells use the media you pick below (or the V2 clip at the same time, if there is one). Renders in the preview and in the Canvas export; the Video Engine export lists it as skipped.

Chroma key / green screen

Removes one colour from the SELECTED video clip (real canvas keying in the preview and in the Canvas export, composited over the V2 clip at the same time, or black if there is none). Tap the colour swatch, then tap the video frame to pick the colour from the picture.

Mask (selected clip)

Masks the selected video clip. Shape, linear and radial masks render in the Canvas export (feathered edges fade to black); the preview shows an approximate clip-path. “None” removes the mask.

Proxy preview (large videos)

For videos 60 s or longer, or files 100 MB or larger, a low-res 480p proxy is generated on import (Video Engine, on-device) so the preview stays smooth. The preview can use the proxy; exports ALWAYS use the original file.

Speed

Clip speed 0.25×–2× changes the selected video clip’s length on the timeline (faster = shorter). Select a video clip first. Preview playback speed is the dropdown above.

Speed ramp (speed keyframes)

Speed varies over the clip: add a keyframe at an offset inside the selected clip with a speed, and playback ramps between keyframes. Renders in the preview and in the Canvas export; the Video Engine export lists it as skipped (it cannot vary speed inside one re-encoded clip).

Time remapping

Map output time → source time inside the selected clip. Add points (output s, source s); playback follows the line between them. Overrides the speed ramp while it has 2+ points.

Frame hold

Hold one frame still for N seconds inside the selected clip (the picture freezes, the timeline keeps running).

Export Center

Video Engine (FFmpeg.wasm) loads from the app itself the first time and re-encodes a real MP4 with trim, speed, color, filters, curves, LUT and true reverse — plus the fade-family transitions (Fade, Fade Black/White, Dissolve, Cross Dissolve, Film Dissolve). Text, captions, V2 overlays, other transitions, effects, HSL and color wheels are burned in by the Canvas export instead; the FFmpeg path lists anything it skips. If the engine cannot load, the Canvas export runs instead and the result says why. The Canvas path renders each frame on a canvas and encodes it with WebCodecs into a real file with exact timestamps, so slow effects only make the export take longer — the file always comes out at the requested fps and duration. Before rendering it proves the codec really works on this browser (H.264 → VP9 → VP8, AAC → Opus) and names the codec it actually used — on browsers without H.264/AAC (for example Linux Chrome) it writes VP9 + Opus instead. If this browser has no video encoder at all, it says so before rendering and points at the Video Engine. No watermark is ever added.
